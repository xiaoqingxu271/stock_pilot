执行链路

每一步失败都会安全停下，不会带病继续。

  1. 01
    库存检查

    只读；库存 ≤ 0 立即终止，零写入。

  2. 02
    商品映射

    同名商品挂起任务，输出候选，等待人工选定。

  3. 03
    调价提案

    只写 staging，商城公开价格保持不变。

  4. 04
    人工审批

    一次审批覆盖调价 + 上架；拒绝即丢弃提案。

  5. 05
    发布前复核

    提交前再查一次库存；不足则系统撤回提案，商城不变。

  6. 06
    原子提交

    价格、上架状态与审批消费在同一事务内完成。

  7. 07
    最终核对

    只读回读价格与状态，结果写入任务记录。
